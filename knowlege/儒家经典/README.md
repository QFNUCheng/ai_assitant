## 文件说明

- `<书名>/README.md`：该书篇目表
- `<书名>/NN-篇名.md`：单篇原文（每节带标题，段落保留缩进）
- `<书名>/<书名>-全文.txt`：整书合并的纯文本，便于检索与喂给程序
- `目录.json`：机器可读的完整索引

## 数据来源与版权

文本抓取自中文维基文库（zh.wikisource.org），经 MediaWiki API 获取并转为简体。古籍原文属公有领域；维基文库的录入排版依 CC BY-SA 4.0 提供。

古籍原文本身已进入公有领域，可自由使用；引用维基文库时建议按 CC BY-SA 4.0 署名。

## 关于白话译文

**本语料库暂不含白话译文。** 维基文库未提供这五部经典的白话译本，为避免混入来源不明的译文，此处只保留校录原文。
各节数据中预留了 `translation` 字段（当前为 null），后续可批量回填。
